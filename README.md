# World news summary

A fixed, sourced briefing for Wednesday, 11 November 2026. The 15 one-sentence stories are stored in `summary.txt`.

Run `MAKEFUN_OUTPUT_DIR=/tmp/news-output python3 main.py` to copy the briefing to `/tmp/news-output/entry.txt`. The copier requires a nonempty summary of at most 2,000 bytes.
